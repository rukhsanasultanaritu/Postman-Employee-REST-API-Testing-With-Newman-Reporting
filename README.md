# Postman-Employee-REST-API-Testing-With-Newman-Reporting

## About this project
This is an Employee REST API Testing and Automation project using Postman and Newman. The project focuses on creating employees,updating employee information,retrieving employee lists, and searching for employees using different query parameters.
Here we have create automation and generate a newman report.

## Features
- Employee Creation API Testing
- Employee Update API Testing
- Get All Employees API Testing
- Employee Search with Different Parameters
- API Response Validation
- Automated Test Execution with Newman
- HTML Test Report Generation

## Pre-requisites
Make sure the following software is installed on your system:
- Node.js
- Postman
- Visual Studio Code
